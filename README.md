## 설치

**맥** — dmg 를 열고 `CueGO` 를 «응용 프로그램» 폴더로 끌어 놓습니다.

**윈도우** — 설치 파일을 열고 「다음」을 누릅니다 (zip 판은 풀어서 `cuego.exe` 를 엽니다).
처음 열 때 «Windows의 PC 보호»가 뜨면 「추가 정보 → 실행」을 누르세요.
`VCRUNTIME140.dll` 이 없다고 나오면 마이크로소프트 «Visual C++ 재배포 패키지»를 설치하세요.

## 이용권

1.1.3부터 직접 시작하는 7일 전체 기능 무료 체험입니다. 이후 새 공연 시작은 평생 이용권이 필요합니다. 곡·설정·멘트는 보존하며 편집·내보내기할 수 있습니다. 기존 무료 사용자는 업데이트 시 14일 전환 유예를 받습니다.
평생 이용권 코드(`CUE-…`)는 설정 → 이용권에 넣으세요 (기기 5대까지).
