## 설치

**맥** — dmg 를 열고 `CueGO` 를 «응용 프로그램» 폴더로 끌어 놓습니다.

**윈도우** — 설치 파일을 열고 「다음」을 누릅니다 (zip 판은 풀어서 `cuego.exe` 를 엽니다).
처음 열 때 «Windows의 PC 보호»가 뜨면 「추가 정보 → 실행」을 누르세요.
`VCRUNTIME140.dll` 이 없다고 나오면 마이크로소프트 «Visual C++ 재배포 패키지»를 설치하세요.

## 이용권

가입 후 기본 로컬 공연 준비·실행과 같은 Wi-Fi 리모컨 1대 연결은 무료입니다. 내려받은 공연·음원은 인터넷 없이 재생할 수 있습니다.
인터넷 리모컨·인터넷 스태프 화면에는 유료 이용권이 필요합니다. 월 4,900원 · 연 39,000원이며, 실제 결제 금액과 이용 조건은 구매 화면에서 확인하세요.
iPhone·Android 앱에서 구매하고 같은 구매 이메일로 맥·윈도우 이용권을 연결할 수 있습니다. 등록 기기 최대 5대이며, Apple Watch는 연결된 iPhone의 등록을 사용합니다. 이용 기간이 끝나도 이미 시작한 공연을 중단하지 않습니다.

1.3.24는 긴 글이 낱말 가운데서 끊기지 않게 줄바꿈을 손봤습니다. 감독 화면은 작은 폰에서도 남은 초가 항상 보이고, 리모컨은 연결 상태를 먼저 보여 줍니다. 음향 담당자용 ZIP의 음원은 원본이며 볼륨 변화·페이드·반복은 진행표에 따라 직접 조작해야 합니다.
