## 설치

**맥** — zip 을 풀고 `cuego.app` 을 «응용 프로그램» 폴더로 옮긴 뒤 엽니다.

**윈도우** — zip 을 풀고 폴더 안의 `cuego.exe` 를 엽니다 (폴더째 두세요).
처음 열 때 «Windows의 PC 보호»가 뜨면 「추가 정보 → 실행」을 누르세요.
`VCRUNTIME140.dll` 이 없다고 나오면 마이크로소프트 «Visual C++ 재배포 패키지»를 설치하세요.

## 이용권

설치 후 14일은 전부 무료. 그 뒤로는 공연 1개까지 무료입니다.
평생 이용권 코드(`CUE-…`)는 설정 → 이용권에 넣으세요 (기기 3대까지).
