CueGO — Android media playback

Actual release app 1.3.13 (76), recorded on an Android 15 emulator on November 7, 2026. No simulated screens. The 90-second test tone was created for this demonstration; no user music or account credentials appear.

Open / download the original recording

  1. Start show explicitly, then press GO to start local audio.
  2. Return to the Android home screen; the performance continues.
  3. Open notifications: “CueGO — On stage” identifies the active show.
  4. Tap the notification to return; playback position has advanced.
  5. End show and confirm. The foreground notification disappears.

The screen-only recording has no audio track. Android runtime verification separately confirmed an active, unmuted AudioTrack with USAGE_MEDIA / CONTENT_TYPE_MUSIC and a mediaPlayback foreground service (type 0x2) while backgrounded. After ending, no CueGO service remained. The service is only used during a user-started performance to prevent audio interruption; it does not start at boot.
